# プライバシーポリシー（YouTube映像AI要約）

最終更新日: 2026-08-08

「YouTube映像AI要約」（以下「本拡張機能」）は、開発者（以下「開発者」）が提供するChrome拡張機能です。本ポリシーでは、本拡張機能がどのような情報を扱うかを説明します。

## 本拡張機能が扱う情報

### 1. Gemini APIキー

- ユーザーがGoogle AI Studioで取得したAPIキーを、Chromeの拡張機能ストレージ（`chrome.storage.local`）にのみ保存します。
- このキーは**ユーザーのブラウザ内にのみ保存され**、開発者のサーバーを含め、開発者がアクセスできる場所には一切送信・保存されません（開発者はそもそも本拡張機能専用のサーバーを保有していません）。
- ユーザーはいつでも「⋮」→「⚙ 設定」からキーを削除できます。

### 2. 視聴中の動画URL・要約プロンプト・要約結果

- 要約を実行すると、視聴中のYouTube動画のURLと、要約用のプロンプト文が、**ユーザー自身のAPIキーを使って**Google Gemini API（`https://generativelanguage.googleapis.com`）に直接送信されます。
- この通信はユーザーのブラウザとGoogleのサーバー間で直接行われ、開発者のサーバーを経由しません。開発者はこの通信内容（動画URL・プロンプト・要約結果のいずれも）を一切収集・閲覧・保存できません。
- Gemini APIに送信されたデータがGoogle側でどのように扱われるかについては、[Google のプライバシーポリシー](https://policies.google.com/privacy)および[Gemini API 追加利用規約](https://ai.google.dev/gemini-api/terms)を参照してください。

### 3. その他の設定情報

- 選択中のAIモデル、コピー形式（Markdown／リッチテキスト）の設定、ユーザーが作成したカスタムプロンプトの内容も、APIキーと同様に`chrome.storage.local`にのみ保存されます。外部への送信は行いません。

## 開発者が収集しない情報

本拡張機能は、以下を一切行いません。

- ユーザーの識別情報（氏名・メールアドレス等）の収集
- 閲覧履歴・視聴履歴の収集
- 広告表示・トラッキング・アクセス解析（アナリティクス）の実装
- 開発者自身のサーバーへのデータ送信（本拡張機能専用のサーバー自体が存在しません）

## データの削除

保存されているAPIキー・設定・カスタムプロンプトは、「⋮」→「⚙ 設定」から個別に削除できます。また、Chromeの拡張機能管理画面から本拡張機能をアンインストールすると、`chrome.storage.local`に保存されていたデータもすべて削除されます。

## ポリシーの変更

本ポリシーの内容は、本拡張機能の機能追加・変更に伴い改定される場合があります。重要な変更がある場合は、本ページを更新します。
